# maxims

maxims installs one-line rule memories from GitHub repos or local folders into the always-loaded instruction layer of every coding agent on a machine, and keeps them fresh with one session-start hook per agent. This page is the index of the documentation; each linked page owns its facts.

```bash
npx maxims add @Vivswan/skills -g --rule --add-hook
```

| I want to... | read |
| --- | --- |
| understand the problem maxims solves and the two-layer design | the overview page, written as the code lands |
| run a command and see every flag | the CLI reference, rendered from the flag table in the code |
| know which agents are supported and what each one gets | the harness matrix, rendered from the harness definitions |
| read the threat model and its guards | the security page |

The documentation grows with the code: a page is added when the behavior it describes exists and is tested, never before.
